## Meta keys for images - exiftool

1. Make - Make of the camera (Nikon)
2. Camera Model Name - Model name of the camera (NIKON D5300)
3. File Size
4. Image Size (resolution) - 6000x4000
5. Create Date
6. If "gps_latitude" and "gps_longitude" exists then run "exiftool geolocation api to find out
the city, region, subregion, country" and index  them as well.
